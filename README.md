# Проект Plaindoll

Данный проект представляет собой Java-приложение (Plaindoll) с полностью настроенным конвейером непрерывной интеграции и доставки (CI/CD).

## 🚀 Особенности
* **Основная логика:** Java-приложение
* **Инструмент сборки:** Apache Maven.
* **CI/CD Pipeline:** Автоматизированная сборка и деплой через TeamCity.
* **Управление артефактами:** Автоматическая загрузка релизных артефактов в Nexus Repository Manager.

## 🛠 Технологический стек
* **Язык программирования:** Java
* **Система сборки:** Maven
* **CI-сервер:** TeamCity
* **Репозиторий артефактов:** Nexus
* **Система контроля версий:** Git

## 🏗 Процесс CI/CD (Workflow)
Проект настроен на автоматизированный цикл выпуска релизов

## 📋 Как собрать проект локально
Для сборки проекта и запуска тестов на локальной машине используйте команду:
```bash
mvn clean install
```
Для деплоя проекта в репозиторий Nexus:
```bash
mvn clean deploy -Dnexus.username=admin -Dnexus.password=ВАШ_ПАРОЛЬ
```

## ⚙️ Детали конфигурации
* **Настройки Maven:** Аутентификация для Nexus управляется через файл settings.xml
* **Управление дистрибуцией:** URL целевого репозитория прописан в pom.xml в секции <distributionManagement>.
* **Пути артефактов в TeamCity:** Настроены как target/*.jar для автоматического подхвата всех собранных файлов.
